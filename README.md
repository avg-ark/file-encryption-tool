This project is a Python-based file encryption tool that securely encrypts and decrypts files using a password. When a user chooses to encrypt a file, the application generates a secure encryption key from the password, encrypts the file, and saves it as a .enc file. To decrypt the file, the user provides the same password, and the application restores the original file. If an incorrect password is entered, the program displays an error message to prevent unauthorized access.
